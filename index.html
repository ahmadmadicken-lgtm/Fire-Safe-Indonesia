Panduan Lengkap APAR

Cara penggunaan, jenis media pemadaman, dan kelas kebakaran.

Metode P.A.S.S.

Teknik internasional yang diakui untuk penggunaan APAR secara efektif dan aman.

P

Pull

Cabut pin pengaman (safety pin) dari handle APAR

A

Aim

Arahkan nozzle ke bagian bawah / pangkal api

S

Squeeze

Tekan handle (lever) untuk mengeluarkan agen pemadam

S

Sweep

Sapukan nozzle dari sisi ke sisi hingga api padam

⚠️ Penting Diingat

  • Posisi punggung selalu menghadap pintu keluar
  • Jaga jarak aman 2–3 meter dari api
  • Jika api tidak padam dalam 30 detik, segera evakuasi
  • Hubungi Damkar (113) sebelum atau saat memadamkan api

Inspeksi Bulanan

  • Cek jarum pressure gauge masih di zona hijau
  • Pastikan pin pengaman masih terpasang
  • Periksa nozzle bebas dari penyumbatan
  • Pastikan posisi mudah terlihat & dijangkau

Servis Tahunan

  • Uji bocor tabung dan valve
  • Ganti segel & pin jika perlu
  • Timbang isi (untuk CO₂)
  • Update label tanggal servis

Isi Ulang / Refill

  • Segera refill setelah digunakan
  • Isi ulang setiap 5 tahun (powder)
  • Isi ulang setiap 3 tahun (CO₂)
  • Gunakan jasa bersertifikat SNI

Penempatan yang Benar

  • Gantung di ketinggian 120–150 cm (handle)
  • Dekat pintu keluar / jalur evakuasi
  • Hindari paparan panas langsung & sinar matahari
  • Pasang tanda APAR yang terlihat jelas

Tools

Tracker Servis APAR

Pantau jadwal inspeksi, isi ulang, dan servis APAR Anda.

1

Tambah data APAR Anda

Klik tombol + Tambah APAR (pojok kanan atas daftar). Isi ID tabung (mis. APAR-01), lokasi pemasangan, jenis media, kapasitas, dan tanggal servis terakhir.

2

Pilih interval servis

Pilih interval 6 bulan (CO₂ / risiko tinggi), 12 bulan (standar umum), atau 24 bulan (Permenaker min.). Sistem otomatis hitung tanggal jatuh tempo.

3

Baca status warna

Hijau (OK) — aman, lebih dari 30 hari ke jatuh tempo.
Kuning — segera servis, kurang dari 30 hari.
Merah — terlambat! Segera hubungi teknisi.

4

Update setelah servis

Setelah APAR diservis, klik ikon pensil (✏️ edit) pada kartu APAR, perbarui tanggal servis ke hari ini, lalu klik Simpan. Status akan otomatis reset ke Hijau.

💾

Simpan & ekspor data

Data tersimpan otomatis di browser Anda (localStorage). Gunakan tombol ⬇ Ekspor PDF di toolbar untuk mencetak atau menyimpan laporan daftar APAR ke komputer. Cocok untuk dokumentasi K3 perusahaan.

⚠️ Catatan: Data tersimpan di browser ini saja. Jika Anda ganti browser atau hapus cache, data hilang. Selalu ekspor PDF sebagai backup.
